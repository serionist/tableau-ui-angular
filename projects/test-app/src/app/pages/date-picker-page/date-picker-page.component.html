Date Picker

The date picker gives a date input a Date as its value, for a day or a day and a time.

Import

Import TableauUiDatePickerModule and DateValidators from tableau-ui-angular/date-picker. The directive applies to each <input> whose type is date, datetime-local or datetime; the type can't change once set.

Value binding

Bind [(value)]: a Date, or undefined while the input holds no whole date. (valueChange) fires as the user types or picks. A day is midnight, local time; a day and a time is in local time too, and toISOString() gives it in UTC.

Reactive forms

Bind [formControl] or formControlName. min and max limit only the browser's picker, so DateValidators.minDate() and maxDate() check a date the user types. The control is touched when the user leaves the input, and a disabled control disables it.
