Monaco Editor

The Monaco editor, the code editor of VS Code, as a form control or with a value binding.

Set up

  1. Install monaco-editor, an optional peer that only this entry point needs:
  1. Serve its files at monaco-edit, where the editor loads them from: add the second entry here to the assets of the app's build options in angular.json, after the app's own, such as the public folder a new app has.
  1. Import TableauUiMonacoModule from tableau-ui-angular/monaco.

Monaco loads in the browser only, once, after the first render; on the server the editor is an empty element.

Value binding

tab-monaco-editor fills its element, which needs a height.

Input or output What it does
uri Required. Names the document: Monaco keeps one per URI, so each editor on a page needs its own
language Required. The language that colours the text, such as json or sql
[(value)] The text
options Monaco's editor options, such as minimap, readOnly or ariaLabel; a change starts the editor again
theme auto, the default, follows the theme service's light or dark mode; or one of Monaco's, such as vs-dark. Monaco has one theme for the whole page, so give every editor on a page the same
onMonacoLoad A function that gets Monaco before the editor starts, such as to set a language's diagnostics
disposeModelOnDestroy On by default: the document goes with the editor. Off, Monaco keeps it by its URI for another editor
(editorLoaded) Emits Monaco's editor once it runs

Reactive forms

Bind [formControl] or formControlName. The control is touched when the editor loses focus, and a disabled control makes the editor read-only.
