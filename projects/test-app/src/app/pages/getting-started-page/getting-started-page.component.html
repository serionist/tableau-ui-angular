Getting started

Install the package, import a folder's module, import the styles once, and pick the fonts and icons.

Install

The package is on npm; an Angular 22 app has every peer but Monaco already.

Import a module

Each folder of the library is an entry point, tableau-ui-angular/<folder> , with a module named after it: the button is TableauUiButtonModule from tableau-ui-angular/button . A standalone component imports the modules it uses. The root, tableau-ui-angular , exports nothing.

Import the styles

The app's global stylesheet uses the library's styles once. This is the docs site's own styles.scss , with the icons and fonts the next sections set up.

Fonts

The text uses the first of these fonts the browser has.

  • Benton Sans, Tableau's font, which needs a licence. With its files in public/fonts , libStyles.font-import('/fonts') loads them. Add-Benton-Sans.md lists the files, and a Tableau Server you own can give them:
  • Roboto, Google's open font, which the Roboto import in styles.scss loads; this site uses it.
  • Arial, then Helvetica, then the browser's sans-serif, with nothing to load.

Icons

tab-icon shows a Material Symbols icon by name. The used-icons script downloads only the icons the app lists, a few kilobytes, into a folder styles.scss uses.
