Theming

The theme service sets the colour mode and the font size; CSS custom properties set the rest.

Start the theme

Call ThemeService.initialize() once, when the app starts. It applies the stored theme, follows the system's mode, and stores each change. Until then the page stays light at the default size; on the server it does nothing. This is the docs site's own app.config.ts:

Dark mode and font size

setColorMode() takes light, dark or auto, which follows the system; the service puts the dark-mode class on the root element and the body. setFontSize() sets the base size, which the library's other sizes follow, and reset() goes back to the default. $theme and $appliedThemeMode give the current choice as signals, and theme$ and appliedThemeMode$ as observables.

CSS custom properties

Every colour, font and size is a custom property, set on :root and, for dark mode, on :root.dark-mode, body.dark-mode, since the theme service puts the class on both. Set one on an element to change it inside that element, or on those selectors in styles.scss to change it for the app: a colour set on :root.dark-mode alone stops at the body, which has its own.

Accessibility

Error text, the primary drawn as text, an icon, a border or the checkbox's and the radio button's focus rings, and the error and primary buttons' labels read at 4.5:1 or more, the contrast WCAG asks of body text and more than the 3:1 it asks of borders and rings, on every surface the library draws them on, at rest and under the pointer, in light and in dark. For its own error text, such as a negative number, an app reads var(--twc-color-error) rather than copying the value, so the text follows the theme. Text an app puts on --twc-color-error, such as a count badge, takes --twc-color-base, as the raised error button now does: a light text there reads below 4.5:1 on the dark theme's red. An app that sets one of these colours keeps each pair at 4.5:1, --twc-color-base on --twc-color-error included.

The library draws the primary on the page's surfaces, as text, icons, a stroked button, the checkbox's and the radio button's focus rings or a selected option's outline, in --twc-color-primary-on-base. In light it is --twc-color-primary itself; in dark, where the primary is 2.56:1 on the base, it is a lighter blue. Fills keep --twc-color-primary under --twc-color-on-primary, and a raised primary button's label under the pointer takes --twc-color-base. An app that sets --twc-color-primary sets --twc-color-primary-on-base beside it, at 4.5:1 on --twc-color-base, --twc-color-mouse-highlight and --twc-color-highlight, as the green row of the sample above does: in dark always, on :root.dark-mode, body.dark-mode, and in light wherever it isn't :root, since on :root the light one follows it by itself. An app that sets --twc-color-primary-dark keeps --twc-color-base on it at 4.5:1; --twc-color-on-primary colours the raised label at rest only.
