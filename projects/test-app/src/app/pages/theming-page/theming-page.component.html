Theming

The theme service sets the colour mode and the font size; CSS custom properties set the rest.

Start the theme

Call ThemeService.initialize() once, when the app starts. It applies the stored theme, follows the system's mode, and stores each change. Until then the page stays light at the default size; on the server it does nothing. This is the docs site's own app.config.ts:

Dark mode and font size

setColorMode() takes light, dark or auto, which follows the system; the service puts the dark-mode class on the root element and the body. setFontSize() sets the base size, which the library's other sizes follow, and reset() goes back to the default. $theme and $appliedThemeMode give the current choice as signals, and theme$ and appliedThemeMode$ as observables.

CSS custom properties

Every colour, font and size is a custom property, set on :root and, for dark mode, on :root.dark-mode. Set one on an element to change it inside that element, or on those two selectors in styles.scss to change it for the app.
