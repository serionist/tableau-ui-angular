CSS & Fonts

The library's styles, which an app uses once, and the fonts its text is set in.

The styles

Use them once, in the app's global stylesheet. They are SCSS: an app made with CSS renames src/styles.css to src/styles.scss, there and in angular.json. as libStyles names them for font-import, below.

They hold the theme's custom properties, which Theming lists, and the components' shared styles. They also style the page: its font, size and colours, the headings h1 to h4, links, scrollbars, and a few text classes.

Fonts

The text is set in the first of these fonts the browser has, from --twc-font-family: {{ fontFamily }}. On a screen of 120 dpi or less, it is {{ lowDpiFontFamily }}.

Benton Sans

Tableau's font, which needs a licence. font-import declares its faces, given the URL the app serves its files at: /fonts for public/fonts. Each face loads its file's WOFF2, or else its WOFF.
