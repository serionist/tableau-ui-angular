Dashboard

A Tableau-style sales dashboard of the library's components, which moves its table's columns with the Angular CDK, and its source.
  • Its frame is the enhanced table, below: a header row with an Actions menu, the selection button, a product search, Filters with the number in use, and Layout & Sorting, which open a drawer.
  • The filters: a multi select, a single select, a button toggle, two date pickers, a customer search with suggestions and two checkboxes. Each filter in use shows as a chip, which clears it.
  • The KPIs, the charts, the orders and the products follow the filters and the search. A KPI's tooltip says how it is counted.
  • The Orders tab holds 3,000 orders, made in the code, in the virtual table: a header sorts them, the checkboxes select them, and the button by an order's number opens its details in a dialog. The Products tab has a panel per category.
  • The selection button's menu copies the selected orders to the clipboard or clears the selection; the Actions menu copies every order the filters keep, or resets the filters. A copy and a reset say so in a snack.
  • The charts are SVG in the template, since the library has no charts; the page adds no chart library.
  • On a narrow dashboard, the drawer covers it while it shows.

The enhanced table

app-enhanced-table frames a table, which it finds anywhere in its content. Layout & Sorting stripes the rows, and shows, hides, moves and pins the columns; Save keeps the layout and the sort in the viewer's browser, and Reset goes back to the saved layout or the default. A column moves by its handle, dragged, or focused and moved with the up and down arrows. Opening a panel puts the focus in it; Escape in it closes it, and the focus goes back to its button.

Input, output or template What it does
uniqueId Required. Names the layout a viewer saves
selectionButtonText The selection button's text; the button shows while rows are selected, when there is a selection menu
searchLabel, [(search)] The search field's name, without which there is none, and its text
activeFilters, (clearFilters) The number the Filters button shows, and Clear all filters
drawerWidth The drawer's width beside the content, 20rem by default
(drawerOpened) The panel the drawer opened on, filter or layout
ng-template headerBeforeSelect, headerAfterSelect The header row's content left and right of the selection button
ng-template buttonMenu selectMenuButtons The selection button's menu
ng-template filterPanel The filters in the drawer

It moves columns with @angular/cdk/drag-drop, so an app that copies it installs the package at its Angular major:

@for (file of tableFiles; track file.label) { {{ file.label }} }
