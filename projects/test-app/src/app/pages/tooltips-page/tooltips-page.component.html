Tooltips

A tooltip shows a text or a template beside an element while the pointer is over it.

Import

Import TableauUiTooltipModule from tableau-ui-angular/tooltip.

A text

tooltip goes on any element. A tooltip opens when the pointer enters the element and closes when it leaves; keyboard focus doesn't open one, so put nothing in one that a user needs.

  • tooltipPosition is top, the default, bottom, left or right. A tooltip that would leave the window moves to the other side.
  • tooltipMargin is its distance from the element, 0.5rem by default; a number without a unit is in pixels.

A template

[tooltip] takes a template too, and [tooltipContext] its context. tooltipArgsMode says where the tooltip's arguments come from:

Mode The arguments
individual, the default The inputs above, one by one
full [tooltipFullArgs], one object: the template, its context, the position, the margin, and the padding, 0.5rem by default
lazy [tooltipLazyArgs], a function the tooltip calls each time the pointer enters; when it gives undefined, no tooltip opens
