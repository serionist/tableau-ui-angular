Table

A table shows rows of data in columns, drawing only the rows that show, however many there are.

Import

Import TableauUiTableModule from tableau-ui-angular/table , and the data options, FullDataOptions and IncrementalDataOptions , from tableau-ui-angular/virtualize . The table measures and loads in the browser only: call load() once it is drawn.

A first table

A column is a tabColumnDef with a header and a cell template. FullDataOptions loads every row at once, sorted as the request says; click a header to sort.

Every option

Data loaded in blocks or at once, with no rows, two, or an error; columns shown, striped, pinned, resizable, sortable, with their own classes and tooltips; a template for no data; and single or multiple selection, by checkbox or by row, with a header checkbox and when a reset clears it.
