Table

A table shows rows of data in columns, drawing only the rows that show, however many there are.

Import

Import TableauUiTableModule from tableau-ui-angular/table, and the data options, FullDataOptions and IncrementalDataOptions, from tableau-ui-angular/virtualize. The table measures and loads in the browser only: call load() once it is drawn.

A first table

A column is a tabColumnDef with a header and a cell template. FullDataOptions loads every row at once, sorted as the request says; click a header to sort.

Every option

Data loaded in blocks or at once, with no rows, two, or an error; columns shown, striped, pinned, resizable, sortable, with their own classes and tooltips; a template for no data; and single or multiple selection, by checkbox or by row, with a header checkbox, each row's checkbox named by rowLabel, and when a reset clears it.

Accessibility

The table scrolls in its own host, which is in the Tab order, so the keyboard scrolls it in every browser, even when nothing in its rows takes focus.

  • A table that scrolls needs label, which names it for screen readers: its host is then a region of that name, and its table too. A static aria-label on tab-table names it the same way, and label wins. Without a name the host has no role.
  • A static tabindex="-1" on tab-table takes it out of the Tab order, as for a short table whose cells hold controls of their own. A tabindex an app put on a wrapper so the keyboard could scroll the table can go.
  • Once the host has focus, the arrow keys, Page Up, Page Down, Home and End scroll it, and the rows they reach load.
  • A row whose block failed shows a red bar in each cell, which a screen reader reads as "Failed to load".
  • A static role the app writes on tab-table stays.
  • The header row and each data row are rows, the data rows in a row group. The table says how many rows it has, the header row included, and each row its place in the whole data, so a screen reader says which row it is on though only the rows near the view are drawn. Until a load says the total, the count is unknown. "No data available" is a row with one cell across the columns.
  • Enter, Space or a click on a sortable header sorts by its column, and focus stays on its button, whose tooltip shows the new sort. With sortMode="multi", Shift+Enter, Shift+Space or Shift+Click adds the column to the sort. The first sort's column header says its direction (aria-sort); a later sort's button says its place, "sort 2, descending".
  • With selection on, each row's checkbox is named "Select" and the name rowLabel gives the row, such as "Select User 12", or its place without one, "Select row 12". The header's checkbox is named "Select all rows" or "Clear the selection", and the column "Selection". Each loaded row says whether it is selected (aria-selected).
  • A resizable column's edge is a separator in the Tab order, after its header's button, named "Resize" and the header's text, such as "Resize Name". A screen reader hears the column's width in pixels, and its minimum and maximum. Right and Left widen and narrow the column by 10 pixels, 50 with Shift; Home and End take it to its minimum and maximum width, or without a maximum to the table's visible width. A mouse, a finger or a pen drags it.
  • Each column header is named by its text alone, so a cell's column is read without its sort's place or its resizer's name.
