Table

A table shows rows of data in columns, drawing only the rows that show, however many there are.

Import

Import TableauUiTableModule from tableau-ui-angular/table, and the data options, FullDataOptions and IncrementalDataOptions, from tableau-ui-angular/virtualize. The table measures and loads in the browser only: call load() once it is drawn.

A first table

A column is a tabColumnDef with a header and a cell template. FullDataOptions loads every row at once, sorted as the request says; click a header to sort.

Every option

Data loaded in blocks or at once, with no rows, two, or an error; columns shown, striped, pinned, resizable, sortable, with their own classes and tooltips; a template for no data; and single or multiple selection, by checkbox or by row, with a header checkbox and when a reset clears it.

Accessibility

The table scrolls in its own host, which is in the Tab order, so the keyboard scrolls it in every browser, even when nothing in its rows takes focus.

  • A table that scrolls needs label, which names it for screen readers: its host is then a region of that name, and its table too. A static aria-label on tab-table names it the same way, and label wins. Without a name the host has no role.
  • A static tabindex="-1" on tab-table takes it out of the Tab order, as for a short table whose cells hold controls of their own. A tabindex an app put on a wrapper so the keyboard could scroll the table can go.
  • Once the host has focus, the arrow keys, Page Up, Page Down, Home and End scroll it, and the rows they reach load.
  • A row whose block failed shows a red bar in each cell, which a screen reader reads as "Failed to load".
  • A static role the app writes on tab-table stays.
