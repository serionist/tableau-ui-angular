Snackbar

A snack shows a short message above the page, at the top or the bottom of the window, for a while or until the user closes it.

Import

Inject SnackService from tableau-ui-angular/snack: one for the app, with no module to import. On the server it shows nothing.

Method What the snack shows
openSnack(message) A message
openSnackWithAction(message, label, action) A message and a button that runs the action
openSnackFromTemplate(template, context) A template, with its context
openSnackComponent(component, data) A component, with its data

Each then takes the duration in milliseconds, 5000 by default and 0 for until the user closes it; the type, info, error or success; and the location, top or bottom. A timed snack waits while the pointer or focus is on it, and screen readers announce each one. Each method returns a SnackRef: close() closes the snack, and closed$ gives its result.

A message

An action

The action gets the snack, which stays open until the action closes it.

A template

The context is the template's, which its let- variables read.

A component

The component reads its data with injectSnackData(), and closes the snack with a result through injectSnackRef().
