Drawer

A drawer slides in from the left or the right of its container, and the content moves aside.

Import

Import TableauUiDrawerModule from tableau-ui-angular/drawer.

Drawers

tab-drawer-container holds the content and up to two tab-drawer elements, one per side, and fills its parent. Each drawer and the content scroll on their own.

Input What it does
[(isOpen)] Opens and closes the drawer
position left, the default, or right
width Required. The drawer's width
padding Half the gap between the drawer and the content, 0.5rem by default
border The border between them, a CSS border

Accessibility

  • A closed drawer is inert: Tab skips it, and screen readers don't read it.
  • The app moves focus into a drawer it opens, such as to its heading, as the dashboard does, so a keyboard user doesn't tab through the page to reach it.
  • A drawer that opens after the page's first render puts focus back where it was before it opened, when it closes with focus inside and that element is still in the page.
  • A drawer open from the first render has nowhere to put focus back, so the app moves focus when it closes that drawer.
