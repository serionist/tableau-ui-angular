Buttons

Buttons run actions; a button toggle picks one of a few options.

Import

Import TableauUiButtonModule from tableau-ui-angular/button, and TableauUiButtonToggleModule from tableau-ui-angular/button-toggle. Every <button> and <a button> in a template that imports the module is a Tableau button.

Stroked

The default kind. Set color to plain, secondary (the default), primary or error; [loading] shows a spinner and stops clicks, as [disabled] does. Each button here loads for two seconds when clicked.

Raised

kind="raised" fills the button with its colour.

Links

<a button> takes the same inputs, for a button that navigates.

Icon buttons

layout="icon" and layout="small-icon" size the button to its icon, for each kind, colour and state.

Button toggle

tab-button-toggle picks one of its tab-options: bind [(selectedValue)]. An option takes an icon, a text or both, and can be disabled, as can the whole toggle. Name the toggle with aria-label, and give an option with only an icon a text hint, its name.

Accessibility

A button toggle follows the WAI-ARIA radio group pattern: its options take the focus, not the toggle.

  • The toggle is a radiogroup, named by the app's aria-label or aria-labelledby on tab-button-toggle.
  • Each option is a radio that says whether it is checked or disabled, named by its text. An option with only an icon is named by its text hint, which its tooltip shows when it takes focus from the keyboard; a template hint names nothing.
  • The toggle is one Tab stop: the checked option, or the first enabled one while none is checked. A disabled toggle is out of the Tab order. Code that focused the toggle focuses its checked option.
Key, on an option What it does
Right, Down Checks the next enabled option, past the end to the first, and moves the focus to it
Left, Up Checks the previous enabled option, past the start to the last, and moves the focus to it
Space Checks the option that has focus
