Buttons

Buttons run actions; a button toggle picks one of a few options.

Import

Import TableauUiButtonModule from tableau-ui-angular/button , and TableauUiButtonToggleModule from tableau-ui-angular/button-toggle . Every <button> and <a button> in a template that imports the module is a Tableau button.

Stroked

The default kind. Set color to plain , secondary (the default), primary or error ; [loading] shows a spinner and stops clicks, as [disabled] does. Each button here loads for two seconds when clicked.

Raised

kind="raised" fills the button with its colour.

Links

<a button> takes the same inputs, for a button that navigates.

Icon buttons

layout="icon" and layout="small-icon" size the button to its icon, for each kind, colour and state.

Button toggle

tab-button-toggle picks one of its tab-option s: bind [(selectedValue)] . An option takes an icon, a text or both, and can be disabled, as can the whole toggle.
