Menu

A menu opens from an element on a click: any content, or a list of items with submenus.

Import

Import TableauUiMenuModule from tableau-ui-angular/menu, and for a list of items TableauUiMenuButtonModule from tableau-ui-angular/menu-button.

A menu

A template marked menu holds the content, and [attachedMenu] opens it from an element on a click. The element says whether the menu is open, through aria-expanded.

Input or output What it does
menuLocation bottom, the default, top, left or right; the menu moves to the other side when it would leave the window
width, minWidth, maxWidth CSS widths, or parentWidth for the element's width
height, minHeight, maxHeight CSS heights
closeOnBackdropClick, closeOnEscape Close the menu on a click outside it, and on Escape; both on by default
(opened), (closed) Emitted as the menu opens and closes; open() and close() do it from code

Menu items

A template marked buttonMenu holds a tab-menu-button-group of tab-menu-button items. An item that holds items opens them as a submenu; any other emits (clicked) and closes the menu. The arrow keys move through the items, and Enter or Space runs one.

  • color is secondary, the default, plain, primary or error.
  • [disabled] and [loading] keep an item from running.

Width

A buttonMenu is at least as wide as its element, as its minWidth is parentWidth by default. Another minWidth, such as fit-content, lets it fit its items.
