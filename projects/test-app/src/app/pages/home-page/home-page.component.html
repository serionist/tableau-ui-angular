Tableau UI for Angular

Tableau-style components for Angular 22: buttons, form controls, selects, a virtual table, dialogs, menus and more.

About

tableau-ui-angular is an open-source component library on npm. Not affiliated with or endorsed by Tableau or Salesforce.

The source is at github.com/serionist/tableau-ui-angular .

Where to start

  • Getting started : install, import a module, the styles, the fonts and the icons.
  • Theming : dark mode, the font size and the CSS custom properties.
  • Server-side rendering : what renders on the server, and what waits for the browser.
  • The component pages, in the menu: each sample on a page shows its source under it, with a copy button.
