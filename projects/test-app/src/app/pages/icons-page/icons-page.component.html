Icons

An icon shows a Material Symbols icon by its name, in the style, weight and fill the app picks.

Import

Import TableauUiIconModule from tableau-ui-angular/icon, for tab-icon.

An icon

  • value is the icon's name on Google Fonts' Material Symbols page, such as home.
  • label names an icon that means something alone, such as the only content of a button. Without one, an icon is decorative, and hidden from screen readers.
  • An icon is 1.2 times the font size around it, so the font sizes it; fontSize gives it a size of its own.
  • color is primary, success or error, the theme's colours; the CSS color gives any other.

Style

The inputs pick the icon's font and its variable axes. An app that downloads its icons lists each one it uses, below.

Input Values
type Material Symbols Rounded, the default, Material Symbols Outlined or Material Symbols Sharp
[fill] true fills the icon; false by default
[weight] 100 to 700, in hundreds; 400 by default
[grade] -25, 0, the default, or 200
[opticalSizePx] 20, 24, the default, 40 or 48
[params] Any of them, with color and fontSize, in one object; each one it sets wins over its own input

Loading the icons

The app loads the icons' fonts in its styles.scss, in one of two ways; this site uses the script.

Way What the browser downloads What the app keeps
The used-icons script Only the icons the app lists, in the styles it lists: kilobytes The list, in src/icons.ts
The material-symbols package Every icon, in every weight, grade, optical size and fill: several megabytes per style Nothing

The used-icons script

The script ships with the package. It compiles the list with the app's own typescript, which an Angular app has, and downloads the icons' fonts and their CSS into a folder of the app.

  1. List the icons in src/icons.ts, in a class named Icons, which the script reads, that extends UsedIcons from tableau-ui-angular/used-icons. With the library's own, this list downloads {{ iconCount }} icons in {{ fontCount }} fonts.
  1. Run the script from the app's package.json: prebuild runs it before npm run build, and icons:watch runs it again whenever src/icons.ts changes, while npm start serves the app.
