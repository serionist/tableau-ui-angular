List

A list shows its options in place, and the user picks one value from it, or several.

Import

Import TableauUiListModule from tableau-ui-angular/list for tab-list-single-select and tab-list-multi-select, and TableauUiCommonModule from tableau-ui-angular/common for tab-option. Each list is a listbox, for screen readers.

Options

A tab-option takes its text and hint as values or as templates, an icon with its [iconParams], and can be disabled. Without a form, bind [(value)].

Focus and display

A click picks an option. With the list focused, the up and down arrows move the highlight, and Enter or Space picks the highlighted option.

Input What it does
focusMode strong, the default, puts the list in the Tab order with a focus ring; silent with a faint one; none leaves it out of the Tab order
selectedCheckIconLocation Where a check marks the selected options: none, the default, left or right
[selectedItemHighlight] Highlights the selected options; true by default
[itemTemplateContext] Which of an option's icon, text and hint show
[disabled] Nothing can be picked, and the list is out of the Tab order

Height

A list is as tall as its options, unless its parent has a height: then the list fills it, and its options scroll inside it.

Reactive forms

Bind [formControl] or formControlName. The control is touched when focus leaves the list, and a disabled control disables it. A tab-list-multi-select's value is an array: a click adds an option to it, or takes it out.
