Virtualization

Virtualization is a technique used to improve performance by rendering only the visible items in a list or grid. This is particularly useful for large datasets where rendering all items at once can lead to performance issues.
The Tableau UI library provides a tableau-ui-angular/virtualize entry point that contains classes related to virtualization

Custom Virtualization

A custom VirtualizeBaseComponent abstract class is provided to build your own virtualization mechanism.
It contains inputs related to data row height and a DataManager class which can be used to load windowed data based on the scroll position.

Virtualize Component

A basic VirtualizeComponent is also provided.
To use the component, import TableauUiChipModule
