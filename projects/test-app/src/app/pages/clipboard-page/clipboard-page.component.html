Clipboard

The clipboard service copies text to the clipboard and reads it back.

Import

Inject ClipboardService from tableau-ui-angular/clipboard: one for the app, with no module to import.

Copy and read

Method What it does
writeText(text) Copies the text
readText() Resolves the clipboard's text; the browser may ask the user first

When the browser refuses, or has no clipboard, as on a page that isn't https or localhost, the call rejects with an error that says why, and the service shows it in an error snack. Block this site's clipboard permission in the browser to see it.

Handle the error yourself

With false as the last argument, the service shows no snack, and the app says what went wrong.
