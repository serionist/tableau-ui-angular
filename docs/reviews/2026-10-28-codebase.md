# Codebase review, 2026-10-28

- **Scope:** the library (`projects/component-library/`), the repo's build files, the CI workflow and the docs, at
  local `main` `9ed59f6`. That is `origin/main` (`c6baaba`, published as 0.1.128) plus 8 unpushed commits: the
  virtualize container and the chip control.
- **How:** five fresh reviewers, one per area, read only, against the lenses in the plan's harness design. Each
  blocker and major then went to a fresh refuter. F3 was also reproduced in headless Firefox 143.
- **What follows:** the findings feed the modernization plan, `docs/plans/2026-10-28-modernization.md`, step S7 (S1 for F1, F2 and F119).

## Verdict

The components work in Chrome on the happy path. Behind that are four kinds of trouble:

- **Two bugs that shipped in 0.1.128 and need a patch now:** a dialog title written as HTML (F1, XSS) and a Monaco
  editor that scrambles typed text (F2).
- **Forms contracts that don't hold:** writes echoed back as user changes (dirty on load), null writes that throw,
  touched set on focus instead of blur, and the typed form wrapper's signals and metas going stale.
- **Accessibility:** the select, autocomplete, list and menus have no ARIA roles, so a screen-reader user hears
  nothing while arrowing; checkboxes and selects in form fields have no accessible name; snacks are never announced.
- **No SSR support:** about 20 places touch `window`, `document` or observers during render (F144).

## Refuted

- **Forms:** `value$` as a new observable per access (cost only); internal subscriptions without `destroy()` (garbage with the form); every radio at `tabindex=0` (browsers keep one per group); Space toggling the checkbox twice (`preventDefault` on keydown stops it); the radio label selecting twice (guarded); the form-field selector order (tree order finds the right element); duplicate values in the default check; `MetaImpl.compare` on object errors (extra emissions only); touched on change in checkbox and radio (works with `markAllAsTouched`); only the first hint's `showOnError` (cosmetic); `resetWithDefaultValue` keeping rows (Angular's own behaviour); `providedIn: 'any'` (works on 20).
- **Select group:** the chip's X or the clear button submitting a form (`ButtonComponent` defaults to `type="button"`); a click reopening an open select (the backdrop takes it); focus return (options don't take focus; menus restore it); host and document keydown both handling a key (`stopPropagation`); Escape closing two overlays (listeners added mid-dispatch don't run); autocomplete left open on destroy (closed); the hover interval (cleared); the autocomplete `toObservable` (completes on destroy); chip effects looping (they converge); date-picker reading `$type` early (static inputs are set first); ISO strings in the date picker (the contract is `Date`); chips with an `undefined` value dropped (intended); dropdowns clipped by `overflow: hidden` (`position: fixed`); duplicate option values (a dev warning); multi-select ArrowDown not opening (Enter and Space do).
- **Dialog group:** stack splices and z-indexes (one handler per close, strictly increasing); out-of-order closes disabling the page's tab order (`tabbable` skips `-1`); the tree effect looping (writes before reads); `viewChild.required` in the confirmation dialog (static); the auto tree child's parent id (too narrow); tree `track i` (performance); accordion and nav-bar subscriptions (completed on destroy); service timers (no-ops after close); the tooltip on scroll (`mouseleave` fires); the button's `type` default (documented input); `instanceof HTMLLinkElement` (Enter works natively; S8 found it doesn't on an `<a>` without an `href`, and fixed it); Space double-firing (not confirmed); `noFocusOnClick` with assistive tech (no failure found); the loader image's alt (`visibility: hidden`); drawer border widths, empty tooltips, `offsetHeight` (cosmetic); NG0100 in tab-group (not confirmed).
- **Table group:** the blocks signal never notifying (the scroll listener marks the view; it is improvement I10); the virtualize width calc and the line-clamp height (dropped by the browser, no visible effect); resizer listeners (removed on mouseup); the list's 10 ms timer (one-shot); teardown of observers, pipes and tooltips (done); effects writing signals (no loop); zoneless apps (change detection is scheduled); `lineHeight: inherit` (resolves to px); empty data and failing first blocks (no stuck spinner); duplicate keys (per block); the list's forms contract (holds); two tables on a page (separate managers); `load()` called by the app (documented); horizontal scroll (same blocks); shared defaults (per instance); `sortOrder` equality (read directly); shift-click range selection (taste).
- **Packaging group:** cross-entry relative imports (none); empty `ng-package.json` (the default entry exists); `sideEffects: false` (no JS side effects); `./styles` missing from `exports` (Sass falls back to the package root); the icon script under `exports` (resolves); the built-in icon list (complete); the Monaco loader's sources (`<base href>` or the origin); `new Function` in the icon script (the consumer's own file); `Math.random` ids (DOM ids only); the Pages URL and the base href (standard); the version re-bump (same number); Benton Sans files (git-ignored); `.editorconfig` against Prettier (style); the vertical separator (layout choice); `@import` in the README (works); `$appliedThemeMode` (primitive); the lock file's version (the known auto-bump).
