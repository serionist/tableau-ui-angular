## Refuted

Places the primary is still drawn as text, an icon, a border, a ring or a line (none; the rest are fills, with their
label at 6.09:1 and 5.19:1); the new colour's ratios on every surface it sits on (4.91:1 and up); other components
drawing the primary; the raised hover label in light (13.53:1, looks the same) and dark (5.22:1, a decided call); the
selected outline at full strength clashing with the list's focus ring; the light value following a primary set on
`:root`; apps that set the dark class on the body only (2.56:1, up from 1.51:1); server rendering and the theme
service; `color-mix()` support; vacuous tests; the README's images (nothing in frame changes, no retake); the one-way
door (one property added, named, agreed in #133); the plan's lines.
