## Refuted

A stale Shift reaching a later click (a pointer click ignores it; a keyboard click follows its own keydown); the
listener disturbing other keys or the button's Space; Shift+Enter and Shift+Space in both browsers; the table's role
tree (the header row in the table, the data rows in a row group, the spacers hidden, axe with no rule off); the count
and indexes after a reset, a failed first block, and with selection on or off; no count with no rows; `aria-sort` on
the first sort only; `aria-selected` on table rows (a plan decision); "Select row 12" against row index 13 (a plan
decision); "Selection" read twice; the hidden text's layout; the count under OnPush; server rendering; the pipe as a
one-way door (declared, not exported); the API file's aliases; the pipe's cost; a Breaking line for the names or the
focus change; vacuous tests.
