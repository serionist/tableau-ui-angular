## Refuted

Round 1: descriptions on hosts without a role (each has one); an id pointing at a missing element; hydration (not
supported); the server; an observer leak or loop; many fields flooding; two radiogroups with a fieldset; the label
joining the app's `aria-labelledby` as Breaking; `aria-invalid` with the group's own error; the ring clipped; the
contrast spec's page; forced colours; the dashboard's narrowed query; the coverage floor; the forms contract.
Round 2: round 1's fixes in Chromium and Firefox, including a field in a modal; the wrapper's overflow; `:has`
support; valid controls and doubled rings; focus moving between fields; the region's own writes; teardown; the
specs. Round 3: every writer's convergence, a block splitting another's, the guard, `aria-invalid`, the chip
control's layout and paint order, and each spec failing on the code before it.
