The lint call: the rule, `@angular-eslint/template/role-has-required-aria`, asks every `treeitem` for `aria-selected`.
`aria-selected="false"` on every row would tell a screen reader each node is unselected, in a tree that can't select.
The maintainer approved one disable with its reason, an exception to AGENTS.md's "no new disable". A next-line
disable can't reach the attribute the rule reports on, so an `eslint-disable` above the row's start tag and an
`eslint-enable` as its first child bound it. aria-query tracks ARIA 1.2 on purpose and already has an issue for 1.3,
A11yance/aria-query#556, so no report went upstream; #121 takes the disable out once aria-query follows 1.3.

## Refuted

`aria-expanded` on leaves; levels under `showRootGridLines`; set size and position after nodes are added, removed or
reordered; the Tab stop when the focused node goes; an effect loop; work per row per check; server rendering; a
focusable control inside a `treeitem` as invalid ARIA (ARIA 1.2 gives `treeitem` no presentational children, and the
plan keeps a control's own Tab stop); keys from a control or a nested tree; the button component swallowing the
toggle's `tabindex="-1"`; type-ahead reading child nodes' text; keyboard users losing the toggle's hover tooltip; the
coverage floor's rise to 88; the null binding as a harness blocker (a policy call, decided above).

Round 2: the toggle's click toggling twice; a nested tree's row click handled twice; an app's click handlers on the
content; modifier clicks; `track node` with duplicate keys; a restore loop; focus taken after the user left the tree
(only through F9's branch); server rendering; the disable's scope (ESLint reports a `role` missing its state before,
after and outside the pair, and `valid-aria` still runs inside it) and its reason (accurate, naming #121); other
disables or skips; F3 to F5's fixes.

Round 3: the `closest()` bound (every row carries a `tabindex`, so it stops at the row); a `<label for>` across the
tree's edge; an app's `tabindex="-1"` element keeping its click (documented); `contenteditable="false"`; SVG targets;
a double click (toggles once on text, as the press selects a word); the hidden toggle; Enter on a focused row (no
click); a caret in a field; round 2's focus specs failing without their fixes; a restore loop or race; a checkbox
tree under WebKit's centre press (the control keeps its click, as the rule says); the plan, page and PR body.
