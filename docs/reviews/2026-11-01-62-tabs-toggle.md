## Refuted

The panel's `tabindex="0"` when its first content is focusable (the plan sets it, the panel scrolls, and the APG's
example sets it on every panel); `aria-controls` and `aria-labelledby` pointing at missing elements (every panel is
rendered and hidden); the scroll arrows between a tab and its panel breaking the pattern (they are outside the tablist;
only the docs were wrong, F2); the Firefox strip fix lost on the server or a re-render; the host no longer focusable
(the Breaking line covers it); the icon-only tooltip against the tooltips' same-name rule; the focus rings below 3:1;
a disabled checked option keeping the stop against the pattern; `tabSelected` and `afterActivate` on every arrow (a
decided call, in the Breaking line); signals and change detection; an arrow on a toggle inside a table row; the API
files (printing only, and `label` as the plan sets it); plan ids or banned words outside `docs/plans/`.
